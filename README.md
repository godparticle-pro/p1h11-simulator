# Helix / Light Laboratory
Buildless, dependency-free browser simulator. Serve dist/ with a static web server.

Scientific specification: dist/specification.html
Numerical engine: dist/engine.js
Interface and rendering: dist/app.js

Run `node tests.mjs` then `python validate_reference.py` (NumPy/SciPy) to reproduce validation. The first command writes a temporary reference trajectory to /tmp/helix-reference-input.json; the second compares independent DOP853 dynamics. Both update dist/validation.json. Default validation covers illustrative parameters, not P1H11 calibration.

No molecular/electronic ab initio data are included. Visual chromophores are schematic. The PTC panel is a phase-clock representation, not evidence of a time crystal. Full density-matrix trajectories can be exported from the app.

## v0.2: P1H11 research workbench

The default page now uses `research-engine.js` and a Web Worker. The original v0.1 application remains at `baseline.html` and retains its original engine and validation report.

The supplied chemical drawing and name anchor material identity only. Idealized monomer, pair, helix, bundle and junction geometry feed a complex driven Lindblad model. Spatial Gaussian/LG fields and transverse complex polarization enter the Hamiltonian. Coherent angular dipole radiation derives from the same density matrix. Quantum metric, graph topology, X/Y input comparisons and RF waveform previews have explicit scope labels. See `dist/research-notes.html` for equations, evidence, corrections and next steps.

Validation:
```
node research-tests.mjs
python validate_research.py
```
The second command requires NumPy and SciPy and consumes `/tmp/p1h11-reference.json` generated by the first. It checks ten configurations with independent complex-matrix DOP853 propagation and density-matrix eigenvalues. Current report: 20 passing checks. Step size is selected from the Hamiltonian row norm, capped at 0.5 fs. Exports preserve parameters and actual dt.

Browser checks: default trajectory, pause/scrub, assembly and vortex controls, input comparison, rendered optical/quantum panels, validation report. The current implementation does not model molecular CD quantitatively, full optical propagation, actual RF material response, gel formation or a validated time crystal.

## Development and publication

This public repository is the source of truth for future development. GitHub Actions validates both engines before publishing `dist/` to GitHub Pages. Pull requests run validation without deployment.

Local preview: `python -m http.server 8000 --directory dist`. Install independent reference dependencies with `python -m pip install -r requirements.txt`.

This imports the complete v0.2 simulator and preserved v0.1 baseline from the previous hosting project. Prior hosting Git history is not imported. Future commits are tracked here.

The scientific claim boundaries remain in the model specifications. Future quantum-chemistry jobs require a separate compute backend; GitHub Pages serves the browser app.
